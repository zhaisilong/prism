# OUP authoring template 1.5

Prism distributes selected unmodified source files from the OUP authoring
template bundle (version 1.5, 2026-07-14). Copyright and individual file
notices remain intact. The class and supporting documentation use LPPL
1.3 or later; individual bibliography style notices also apply. A copy of
LPPL 1.3c is included as LICENSE.txt.

Source: https://mirrors.ctan.org/macros/latex/contrib/oup-authoring-template.zip
Package information: https://ctan.org/pkg/oup-authoring-template
Original ZIP SHA-256: 025434f53ed3a46b9fd84d50a78c734c309476bc47b1cb7a90c383734df38e97

The original example TeX, bibliography, documentation TeX and documentation
PDF are omitted from this selection. README and manifest.txt are preserved
verbatim and describe the complete upstream bundle available at the source
above. Prism supplies its own manuscript examples separately. This notice
and the packaging selection are maintained by Prism; upstream authors do
not provide support for Prism's integration.
