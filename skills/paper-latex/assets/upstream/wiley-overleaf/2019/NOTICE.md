The byte check identifies this mirror's source selection. It is not a
checksum or authentication claim for the separate LaTeX ZIP currently linked
by Angewandte Chemie. This copy preserves the original creator attribution.

The original publication explicitly says that this generic template is no
longer supported. It is **not the current Angewandte Chemie official
template**, and its inclusion does not imply endorsement by Wiley, Overleaf
or the journal. Check the journal's current instructions before submission.

Only the class and these source/license notices are retained. No journal
logos, publisher fonts, sample figures, sample PDF or sample bibliography
are copied into Prism. TeX packages and font files are supplied by the
user's TeX installation. The full historical example remains linked from
the original publication page.

Prism's separately named `prism-wiley-article.cls` is a maintained derivative,
also distributed under CC BY 4.0. Its 2026-11-07 changes rename the class,
resolve the same fonts by their TeX-distribution filenames, reuse a single
abstract frame to eliminate unresolved measurement labels, preserve the
line-number option and avoid stretching short draft pages. The original
class in this directory remains byte-identical to the source above.
