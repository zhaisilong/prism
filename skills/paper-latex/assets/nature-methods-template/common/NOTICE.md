# Nature Methods drafting resources

These original Prism writing skeletons and independent supporting examples
are distributed under the repository's MIT license. The figures, tables
and equations are synthetic formatting demonstrations; they report no
research findings. The public bibliography entry illustrates citation
mechanics and is not evidence for the examples.

Nature Methods content types: https://www.nature.com/nmeth/content
Initial submission: https://www.nature.com/nmeth/submission-guidelines/initial-formatting
Acceptance in principle: https://www.nature.com/nmeth/submission-guidelines/aip-and-formatting

This is a Prism writing draft, not a final submission package or an official
publisher template. Nature Methods requests a single TeX text file in default
fonts with embedded references after acceptance in principle. Follow the
current journal instructions when preparing actual files. Bilingual support
adds Chinese fonts and does not translate text. No publisher template package
is downloaded or mirrored. Replace all example text and author placeholders.
