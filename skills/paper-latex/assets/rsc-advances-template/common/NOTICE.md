# RSC Advances draft

This original Prism-maintained drafting template uses the standard LaTeX
`article` class and the TeX distribution's `rsc` package and BibTeX style.
It is not the Royal Society of Chemistry's official template and does not
claim to reproduce the journal's final typeset layout. The package and style
are not redistributed in this project. The official optional article template
and current journal instructions are available at:

- https://www.overleaf.com/latex/templates/royal-society-of-chemistry-article-template/vffpnxpmxdfz
- https://www.rsc.org/publishing/publish-with-us/publish-a-journal-article/rsc-advances
- https://ctan.org/pkg/rsc

All figures, values and chemistry placeholders are synthetic; bibliography
entries are public sources for demonstrating citations, not study evidence.
